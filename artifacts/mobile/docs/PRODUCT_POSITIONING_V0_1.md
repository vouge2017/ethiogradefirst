# EthioGrade v0.1 — Product Positioning

## What EthioGrade v0.1 Is

**EthioGrade v0.1 is an offline manual exam grading and scoring assistant for Ethiopian teachers.**

Teachers can:
- Create an assessment with a title, question count, and mixed question types
- Define per-question weights (points)
- Set the correct answer for MCQ and True/False questions
- Add marking notes/rubric hints for Short Answer and Matching questions
- Enter each student's answers manually (one student at a time)
- Calculate weighted scores automatically
- View class statistics (average, median, pass rate, grade distribution)
- Export results as CSV (for spreadsheet analysis)
- All data is saved offline on the device — no internet required

## Supported Question Types

| Type | Grading in v0.1 |
|---|---|
| Multiple Choice (A–E) | Manual selection, auto-scored against key |
| True / False | Manual selection, auto-scored against key |
| Short Answer | Teacher enters score (0 to max weight) |
| Matching | Teacher enters score (0 to max weight) |

## Why Manual-First?

The goal of v0.1 is to validate the teacher workflow:
- Can teachers set up assessments quickly?
- Is the grading flow faster than pen-and-paper tallying?
- Are the class statistics useful?
- Is the CSV export good enough for reporting?

Real-world feedback from teachers will guide what scanning approach to build in v0.2.

## v0.1 Promise

> A teacher can create an assessment, define mixed question types with weights, enter student answers manually, get weighted scores calculated automatically, view class statistics, and export results as CSV — all offline, on their Android phone.
