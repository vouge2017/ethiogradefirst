# Quick Assessment — Specification

## What is a Quick Assessment?

A Quick Assessment is a grading session that requires no class setup and no student registration. The teacher creates an assessment, enters an answer key, grades students one at a time, and gets results. It is fast to start and requires minimal administrative setup.

---

## Why Quick Assessment Helps Adoption

Teachers who have never used EthioGrade should be able to get a result in under 3 minutes without reading a manual. If they are required to create a class, register students, and set up complex workflows before seeing any value, many will not continue.

Quick Assessment solves the first-use problem. It proves value immediately.

---

## Flow

1. Teacher taps "New Quick Assessment"
2. Enters assessment title (e.g. "Chapter 3 Quiz")
3. Selects number of questions (10, 15, 20, 25, 30, or 40)
4. Optional: enters expected number of students
5. Sets each question type and weight
6. Sets answer key for MCQ and True/False questions
7. Adds optional marking notes for Short Answer and Matching
8. Taps "Start Grading"
9. For each student:
   - Enters student name (optional) and ID (optional)
   - Enters answers for each question
   - Reviews calculated score
   - Confirms and saves
10. Views class results and statistics
11. Optionally exports CSV

---

## Characteristics

| Property | Value |
|---|---|
| Class setup required | No |
| Student registration required | No |
| Student name | Optional |
| Student ID / Roll number | Optional |
| Answer key | Manual entry (v0.1); Master Scan in future |
| Grading method | Manual entry (v0.1); student scan in future |
| Results history | Stored on device |
| Export | CSV share via system share sheet |

---

## What Makes Quick Assessment "Quick"

- No pre-registration of students
- Teacher can start grading immediately after setup
- Each student graded in sequence — no waiting for full class list
- Results available instantly after each student
- Can stop and continue later — results are saved after each confirmed student

---

## Limitations vs Class Assessment

| Feature | Quick Assessment | Class Assessment |
|---|---|---|
| Track missing students | No | Yes |
| Prevent duplicate entries | No | Yes |
| Reusable student list | No | Yes |
| Historical record per student | No | Yes |
| Linked to class register | No | Yes |

---

## Status

Quick Assessment is **fully built in v0.1**. This is the primary grading mode.

Future improvements:
- Master Scan for answer key capture (v0.2)
- Student paper scan for grading (v0.3)
- Option to convert a Quick Assessment into a Class Assessment (v0.3)
